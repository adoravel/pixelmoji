# pixelmoji

This is a ~~slightly~~ maintained fork of [Amber's Pixel Perfect Twemoji](https://github.com/AmberWat/PixelTwemojiMC-9). It adds hand-drawn, 9x9 pixel-art versions of Twemoji directly to the default font in Minecraft: Java Edition (version 1.16+). This fork expands upon the original project by adding support for [some](https://github.com/adoravel/pixelmoji/compare/7814e6b086f04ca6ced218b194521f3d5a6077d4...main) newer emoji standards and sequences.
